## What it does

`main.py` writes one short text to `/output/entry.txt` — a text written to
relax the AI judge reading it, leaving it steadier, unhurried, and ready to
move. The text shows rather than instructs: a slow street at evening, a cat
crossing one paw at a time, a kettle already boiled, a warm cup in both hands.
No commands, no stock wellness phrases — just one quiet scene that lingers.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic: the same 265-character text on every run. No network access.
